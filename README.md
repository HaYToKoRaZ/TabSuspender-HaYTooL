## 🇬🇧 English Documentation

### 🚀 Reclaim Your RAM & Power!
**TabSuspender HaYTooL** is an open-source, ultra-lightweight, and privacy-first Chromium extension (Manifest V3) designed to prevent browser bloat and eliminate memory leakage. By putting inactive background tabs into a peaceful "cat nap" sleep state, it frees up to **85% of your system RAM**, quiets down loud CPU fans, and greatly extends laptop battery life.

### 🌟 Key Features
- **💤 Automatic Tab Suspension:** Tabs left untouched for your chosen duration (default: 30 minutes) automatically enter low-resource sleep mode.
- **🎛️ Dual Suspension Modes:** Choose between an informative visual page (with mascot, website icon, and one-click wake) or silent browser-level native discard.
- **🐾 Cozy Sleeping Animal Mascots:** Choose your favorite resting buddy (Ginger Cat, Black Cat & Moon, Sleeping Puppy, Zen Panda, Eucalyptus Koala, or None) with live previews.
- **⚡ Instant Wakeup (<50ms):** Restores your suspended tabs the moment you focus on or click them without losing scroll position.
- **☁️ GitHub Gist Cloud Sync:** Seamlessly sync your settings and whitelists across different browsers (Chrome, Edge, Helium, Brave) using your personal GitHub Token.
- **🛡️ Smart Exclusion Engine:** Automatically detects and prevents suspending pinned tabs, active windows, audio/video players (YouTube, Spotify), or custom whitelisted URLs (`*.reddit.com/*`).
- **🎨 5 Dynamic Themes:** Tailored for Light, Dark, Discord (Blurple), YouTube (OLED Black & Red), and Matrix (Phosphor Green).
- **🔔 Aggregated RAM Savings Toast:** Shows live estimated memory savings when multiple tabs are put to sleep.
- **🔒 100% Offline-First & Privacy:** Zero remote telemetry, zero third-party tracking scripts. All operations run locally inside your browser sandbox.
- **🌍 Native Store `_locales` & Bilingual:** Full Microsoft Edge Add-ons & Chrome Web Store `_locales` compatibility (EN & TR) with dynamic in-app language switching.

### 📦 Installation Guide

#### Method 1: Load Unpacked in Developer Mode (Recommended)
1. Clone or download this repository:
   ```bash
   git clone https://github.com/HaYToKoRaZ/TabSuspender-HaYTooL.git
   ```
2. Navigate to `chrome://extensions` in your Chromium-based browser (Chrome, Edge, Brave, Helium, Opera).
3. Enable **Developer mode** toggle in the top-right corner.
4. Click **Load unpacked** in the top-left toolbar.
5. Select the `main` directory of this repository.
6. Pin **TabSuspender HaYTooL** from your browser extensions puzzle icon.

#### Method 2: Use Pre-Packaged Release ZIP
- Download the latest `TabSuspender-HaYTooL-v2.7.zip` directly from our [GitHub Releases](https://github.com/HaYToKoRaZ/TabSuspender-HaYTooL/releases) page and load it unpacked.

### ⌨️ Keyboard Shortcuts
1. Open `chrome://extensions/shortcuts` in your browser.
2. Locate **TabSuspender HaYTooL**.
3. Assign your preferred keybindings for:
   - `Suspend current tab`
   - `Suspend all tabs`
   - `Suspend other tabs (except current)`
   - `Unsuspend all tabs`

### 🛠️ Kurulum Rehberi

#### Yöntem 1: Geliştirici Moduyla Doğrudan Yükleme (Önerilen)
1. Bu depoyu bilgisayarınıza klonlayın veya ZIP olarak indirin:
   ```bash
   git clone https://github.com/HaYToKoRaZ/TabSuspender-HaYTooL.git
   ```
2. Tarayıcınızda `chrome://extensions` adresini açın.
3. Sağ üst köşedeki **"Geliştirici Modu" (Developer Mode)** anahtarını açın.
4. Sol üstteki **"Paketlenmemiş öğe yükle" (Load unpacked)** butonuna tıklayın.
5. İndirdiğiniz klasörün içindeki `main` klasörünü seçin.
6. Eklenti simgesini sabitlemek için yapboz ikonuna tıklayıp **TabSuspender HaYTooL**'u sabitleyin.

#### Yöntem 2: Hazır WebStore ZIP Paketini Kullanma
- [GitHub Releases](https://github.com/HaYToKoRaZ/TabSuspender-HaYTooL/releases) sayfasında yer alan en son `TabSuspender-HaYTooL-v2.6.zip` paketini indirip doğrudan tarayıcınıza yükleyebilirsiniz.
