## 🇬🇧 English Overview

### 🚀 Reclaim Your RAM & Power!
**TabSuspender HaYTooL** is an open-source, ultra-lightweight, and privacy-first Chromium extension (Manifest V3) designed to prevent browser bloat and eliminate memory leakage. By putting inactive background tabs into a peaceful "cat nap" sleep state, it frees up to **85% of your system RAM**, quiets down loud CPU fans, and greatly extends laptop battery life.

### 🌟 Key Highlights
- **⚡ Zero-Lag & Instant Wakeup (<50ms):** Restores your suspended tabs the moment you focus on them with no delay.
- **☁️ GitHub Gist Cloud Sync:** Seamlessly sync your settings and whitelists across different browsers (Chrome, Edge, Helium, Brave) using your personal GitHub Token.
- **🛡️ Smart Exclusion Engine:** Automatically detects and prevents suspending pinned tabs, active windows, audio/video players (YouTube, Spotify), or custom whitelisted URLs (`*.reddit.com/*`).
- **🎨 5 Dynamic Themes:** Tailored for Light, Dark, Discord (Blurple), YouTube (OLED Black & Red), and Matrix (Phosphor Green).
- **🔒 100% Offline-First & Privacy:** Zero remote telemetry, zero third-party tracking scripts. All operations run locally inside your browser sandbox.
- **🌍 Bilingual Support:** Turkish (TR) and English (EN) native support.

## 🛠️ Kurulum Rehberi (Installation Guide)

### Yöntem 1: Geliştirici Moduyla Doğrudan Yükleme (Önerilen)
1. Bu depoyu bilgisayarınıza klonlayın veya ZIP olarak indirin:
   ```bash
   git clone https://github.com/HaYToKoRaZ/TabSuspender-HaYTooL.git
   ```
2. Tarayıcınızda adres çubuğuna şunu yazıp Enter'a basın:
   ```text
   chrome://extensions
   ```
3. Sağ üst köşedeki **"Geliştirici Modu" (Developer Mode)** anahtarını açın.
4. Sol üstteki **"Paketlenmemiş öğe yükle" (Load unpacked)** butonuna tıklayın.
5. İndirdiğiniz klasörün içindeki `main` klasörünü seçin.
6. Eklenti simgesini sabitlemek için yapboz ikonuna tıklayıp **TabSuspender HaYTooL**'u sabitleyin.

### Yöntem 2: Hazır WebStore ZIP Paketini Kullanma
- Projenin `.agents/dist/` klasöründe yer alan en son `TabSuspender-HaYTooL-v2.5-WebStore.zip` paketini doğrudan mağaza panellerine yükleyebilir veya arşivden çıkartıp yükleyebilirsiniz.

## ⚙️ Yapılandırma ve Kısayollar

### Kısayol Tuşlarını Düzenleme
1. Tarayıcınızda `chrome://extensions/shortcuts` adresini açın.
2. **TabSuspender HaYTooL** başlığını bulun.
3. Yanındaki kalem simgesine tıklayarak istediğiniz kısayol kombinasyonlarını atayın:
   - `Geçerli sekmeyi askıya al`
   - `Tüm sekmeleri askıya al`
   - `Geçerli sekme dışındakileri askıya al`
   - `Tüm sekmeleri geri yükle`
